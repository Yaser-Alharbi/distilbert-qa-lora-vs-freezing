Fine-tuning efficiency

Low-rank adapters (LoRA) versus layer freezing for extractive question answering

A fine-tuning efficiency study: which method keeps a pretrained language model accurate on a new task while training the fewest of its weights, LoRA or layer freezing?

DistilBERT is adapted to the Stanford Question Answering Dataset (SQuAD) either by retraining its top layers or by training low-rank adapters (LoRA) on every layer.

Method and limitations

Method

Problem. Fine-tuning every weight of a pretrained model for each new task trains and stores a full copy of it; cheaper schemes that train only part of the model often lose accuracy.

Idea. Layer freezing locks the lower layers and retrains only the top few, so the lower layers never adapt to the task. LoRA locks every pretrained weight and learns a small low-rank correction, whose size is set by the rank, added to each linear projection in every layer, so all layers adapt while few numbers are trained.

Terms. Extractive QA: the answer is a span copied from the given passage. Trainable parameters: the weights updated during training. F1: word overlap between the predicted and the correct answer, from 0 to 100.
